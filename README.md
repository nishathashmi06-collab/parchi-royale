# 👑 Parchi Royale

A cinematic multiplayer strategy game built with React, Node.js, Express and MySQL.

---

## 🎮 Current Features

- Multiplayer Rooms
- Create Room
- Join Room
- Random Role Assignment
- Wazir Guess System
- Winner Detection
